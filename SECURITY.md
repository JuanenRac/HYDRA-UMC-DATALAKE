## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In an industrial datalake, a security flaw can lead to intellectual property theft or production sabotage. If you discover a vulnerability affecting the **database authentication**, **SQL injection**, or **backup exposure**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows unauthorized access to production telemetry, modifying historical logs to hide failures, or crashing the storage engine.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
